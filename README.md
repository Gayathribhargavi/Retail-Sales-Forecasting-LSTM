# 📈 Retail Sales Forecasting Using LSTM

## Project Overview
This project predicts future retail sales using an LSTM (Long Short-Term Memory) Deep Learning model.

## Technologies Used
- Python
- TensorFlow / Keras
- Streamlit
- Pandas
- Plotly
- Scikit-learn

## Dataset
- Walmart Weekly Sales Dataset

## Features
- Forecast Future Sales
- Interactive Dashboard
- Dataset Explorer
- Download Forecast CSV
- Streamlit Web Application

## Project Structure

Retail_Sales_Forecasting
│
├── App
├── Dataset
├── Forecast
├── Models
├── Notebook
└── requirements.txt

## Run Project

```bash
pip install -r requirements.txt

cd App

streamlit run app.py
```s
